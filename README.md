## About the Project
This project is created using HTML and CSS. It contains six different tables with different colour themes to display information in an organised and attractive way.

## Tables Included
1. Student Details
2. Employee Details
3. Product Details
4. Course Details
5. Sports Details
6. Book Details

## Technologies Used
- HTML
- CSS

## Features
- Six different HTML tables.
- Different colour themes for each table.
- Coloured table headings and data rows.
- Center-aligned table content.
- Yellow background for the webpage.
- Table borders, spacing and padding.
- Consistent table width and layout.

## How to Run
1. Download or clone the project.
2. Open the project folder in Visual Studio Code.
3. Open the `index.html` file in a web browser.
4. View all six tables.
